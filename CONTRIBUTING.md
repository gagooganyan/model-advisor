# Вклад в Model Advisor

Спасибо за интерес к проекту! Принимаем любые PR.

## Как помочь

### Добавить новый источник бенчмарков

1. Найди публичный источник с проверяемыми тестами (не опросы/рейтинги)
2. Добавь данные в `data/models.json`
3. Обнови секцию «Данные» в `SKILL.md`
4. Отправь PR с описанием источника

### Исправить данные

1. Проверь актуальность через OpenRouter API или Artificial Analysis
2. Исправь в `data/models.json` и `SKILL.md`
3. PR + ссылка на источник

### Переводы

1. Скопируй `README.md` как `README.XX.md`
2. Переведи
3. PR

### Улучшить SKILL.md

- Новые сценарии рекомендаций
- Улучшенный формат ответа
- Новые метрики для выбора модели
- Улучшенные правила анализа ТЗ

## Правила

- Всегда указывай источник данных в PR
- Цены — только из OpenRouter API
- Бенчмарки — только из Artificial Analysis / Design Arena / аналогичных
- Не добавляй «рейтинги» из блогов и опросов
